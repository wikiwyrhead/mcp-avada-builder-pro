# Code of Conduct

This project follows a simple standard: be respectful, constructive, and practical.

## Expected Behavior

- Be respectful in language and feedback.
- Focus on technical issues, not people.
- Assume good intent and ask clarifying questions.
- Provide actionable review comments.

## Unacceptable Behavior

- Harassment, abuse, or personal attacks.
- Discriminatory language.
- Repeated off-topic disruption.
- Sharing private information without consent.

## Enforcement

Project maintainers may remove comments, close discussions, or block contributors for violations.

For serious concerns, report privately via the security contact process in `SECURITY.md`.
